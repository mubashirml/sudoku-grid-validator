# Sudoku Grid Validator

A Sudoku grid validator built with Python and NumPy. The project uses NumPy arrays, indexing, slicing, sorting, comparison, and Boolean logic to validate a standard 9×9 Sudoku grid.

## Project Overview

This project checks whether a Sudoku grid is valid by analyzing:

* Rows
* Columns
* 3×3 subgrids

The validation is implemented using NumPy array operations.

## Technologies Used

* Python
* NumPy
* Jupyter Notebook

## Key Concepts

* NumPy arrays
* Array indexing
* Array slicing
* Sorting and comparison
* Boolean validation
* Row and column analysis
* 3×3 subgrid extraction

## How It Works

The Sudoku grid is represented as a 9×9 NumPy array.

The validator checks each:

1. Row
2. Column
3. 3×3 subgrid

The individual validation results are then used to determine whether the complete Sudoku grid is valid.

## Project File

`05-Sudoku.ipynb`

The Jupyter Notebook contains the complete implementation and analysis.
